MAH STORE - دليل سريع

1) افتح script.js وعدّل STORE_WHATSAPP إلى رقمك بصيغة دولية بدون + أو مسافات. مثال مصر: 201XXXXXXXXX.
2) المنتجات موجودة في بداية script.js داخل المصفوفة PRODUCTS.
   لكل منتج: id رقم فريد، name الاسم، category التصنيف، price السعر بالجنيه، description الوصف، emoji رمز بديل للصورة، image رابط صورة مباشر.
3) لإضافة منتج انسخ سطراً من المنتجات وغيّر البيانات مع جعل id مختلفاً.
4) ضع ملفات الموقع كلها في جذر مستودع GitHub، وتأكد أن اسم الصفحة الرئيسية index.html.
5) من GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
6) بعد ظهور رابط الموقع، أضفه في Google Search Console ثم أرسل خريطة الموقع sitemap.xml إن أضفتها لاحقاً. ابدأ بطلب فهرسة الصفحة الرئيسية.

ملاحظة: هذا متجر واجهة أمامية ثابتة. الطلبات تُرسل إلى واتساب ولا توجد لوحة تحكم أو دفع إلكتروني أو قاعدة بيانات. الصور تُضاف بروابط مباشرة أو ترفع داخل المستودع ثم تضع مسارها في image مثل images/product.jpg.
